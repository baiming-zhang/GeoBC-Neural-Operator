# Neural baselines

This is the three-seed plain-FNO versus Hash-query package confirmation following the [historical backbone screens](../backbone_comparison/README.md). The historical Transolver comparisons retain their own single-seed protocols; they are not rows of this matched three-seed experiment. Both packages here precede the new physical U/gradient predictors.

On the same 20 development CADs and three seeds, FNO U/S/hotspot errors are 21.72/49.33/37.53%; the Hash comparator gives 21.97/48.71/33.24%. FNO remains the smaller joint-field baseline.
