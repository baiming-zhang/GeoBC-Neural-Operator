# 全局算子条件化Hash：接口检查

候选复用FNO完整R64几何／BC／材料算子，将16维空间latent与32维几何descriptor、25维局部特征一起送入连续Hash解码器。FNO骨干初始化与原MLP基线完全相同；Hash解码器沿用已有配置，不作小幅救参。

CPU注入解码器检查通过：原节点／连续点／分块／点重排一致，xyz／局部特征／全局context／latent均有有限非零梯度；坐标AD与FD一致。未初始化CUDA、未读数据／GT／检查点、未训练。此检查不证明真实TCNN梯度、速度、精度或独立离节点FEM准确性。实际实验须在当前FNO100覆盖结果之后按证据选定宏观对照、冻结预算并放行。
