# 唯一下一候选：全节点 PointConv U-Net

2026-10-10，**proposal_only，未选择或执行**。完整 mesh 的接口/资源与七组梯度通过，但480端点 known U/S=106.48%/99.30%、TRAIN readout=112.86%/99.17%，此次不延预算救参；不能据此否定整个 mesh 族。依用户最新“找合适 solver”方向，建议下一家 **PointConv**，不再受旧笔记“仅 mesh 资源失败才启用”限制。其坐标连续滤波核、密度补偿及点集卷积/解卷积，区别于刚完成的 sender/receiver 特征消息与固定拓扑 V-cycle，也区别于 FFT、Hash、低秩 branch/trunk。

**固定结构。** 原全部N节点、原25含force、旧1024 xyz PointNet/global32形成60槽，lift60→64→32得s0；fine为h0=s0+PointConv32→32(s0)，保留原节点identity路径。FPS2048处32→64、同层64→64；FPS128处64→128、同层128→128。解码两次采用 **3NN插值→目标细层PointConv（128→64、64→32）→concat对应fine skip→Linear融合（128→64、64→32）**，最后32→128→4 signed encoded direct4。固定kNN32、核中间宽度16、query块2048、ReLU；无u9、重复V-cycle或第二候选。所有原点都有fine卷积、identity skip与输出；stride kNN仅选局部source，**不声称每一点都进入coarsest或机制因果**。2048/128是两级原节点子集，不是角色聚合、mesh边或均匀面采样。

**核与密度。** stored canonical FP32 xyz已/L，模型δ=xj−xi（source−query），不再/L；邻距选择/KDE用存储值提升FP64。M(δ):3→8→8→16。每source层σ_l=median_j d32(j)；p_j=(1/32)Σ_{k∈32NN(j)}exp(−d²/(2σ_l²))，包含self且σ_l≤0就输入失败，不换规则。有限邻域KDE**非原全点Gaussian KDE**；Gaussian层常数在r_ij=p_j⁻¹/max邻域p⁻¹中抵消。s(r):1→16/ReLU→1/sigmoid，**整个density网络无LN/BN**，不消除输入比例变化。Z_i=(s·F_neighbors)ᵀM∈Cin×16，再Linear(Cin×16→Cout)，无K×Cin×Cout核。WeightNet两个8通道隐藏及PointConv混合输出用逐edge/点非affineLN+ReLU，WeightNet末16只ReLU；lift/head隐藏与skip融合ReLU、最终field线性。chunk规则不改变输出。源算约 **712,131 real parameters**，实际首case测；非容量匹配。

**几何规则同TRAIN/DEV。** 两级纯Torch GPU FPS，从最小原行ID起、max距离并列取最小原ID，O(N)运行最小距离，不N²或循环内.item()同步；若目标数前剩余max距离为零则整体输入失败，不造重复anchor。原重复坐标行及各自输入保留；同层kNN固定self+最近31不同原行，stride固定其原anchor行+31邻居；cutoff tie按(distance,原ID)定32，边界同距候选由精确半径补齐。3NN零距离仅零邻居等权，否则归一化1/d，不加任意距离floor。缓存原row/anchorID、选定邻域与xyz身份，不nearest复制输入/补采样；速度未知，实际prep成本单列。

**输入/计算路径。** 复用40TRAIN/5DEV canonical xyz、features25、原cloud/mask与TRAIN-only scaler，无cells/Field/新下载需求。每CAD一次target-free缓存FPS、三层kNN32、KDE和两个3NN归一化权重；CPU精确KDTree分块检索、GPU FPS/KDE与全部卷积，禁止全N² cdist、邻域额外截断或补采样，缓存身份/实际覆盖与建设成本单列。3NN若有exact-zero距离仅对零距离邻居等权，否则归一化1/d，无最近节点复制。粗点可能漏小BC patch、欧氏邻域可能跨薄壁/孔洞，不能称拓扑/BC保持。N=200k时fine int32邻域约25.6MB、KDE0.8MB、3NN索引/权重4.8MB；45CAD约1.5GB仅算术量级，未测。最大fine解码块2048×32×64 feature约16.8MB，Cin×16中间约8.4MB，**不是反传总峰值**。gather、核/密度MLP、矩阵乘法在non-reentrant checkpoint内；保留完整N latent，各query块拼接，不能每块保留全N buffer。一次encode→H0 leaf，32768读出块完整node/N加权损失→一次原H0 backward；训练不跨步缓存latent。

**一轮判据与边界。** Fresh2026、同120case序四pass/480、Adam.001、完整N signed4 MSE/4与旧scaler，端点0/120/240/480；共享input prep、读入/H2D、训练、全N推断、wall/peak分别实报。known15 U/S mean/worst、最差ID、S热点及固定480 DEV5-dia同列，先看误差—成本机会再决定是否确认；不凭短跑否定族、不自动追加seed/参数扫。历史FNO/mesh/MLP只是跨架构上下文，非严格匹配因果。角色是输入membership而非节点Dirichlet，密度不是FE积分/刚度，节点u梯度代理不是solver GT；不加P1/P2监督或宣称原生off-node连续性/工程合格。旧final与新sealed输入、标签均封存。
