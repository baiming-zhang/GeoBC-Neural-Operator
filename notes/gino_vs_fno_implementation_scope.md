# GINO 与现有 FNO 的实现边界（source-only）

两者均标作 hidden16 / modes12 / 4layers，但**不是同一 FNO 核或容量匹配对照**。GINO 使用官方 NeuralOperator2.0.0、pin `b307030d9b7ee530823d6a05bddb8238ba22a743`；旧 FNO 使用本项目四象限实现。以下只读源码与已完成小 JSON，未执行模型、科学 import、数组/GPU或新检查。

**频率语义是参数差异的主要已确定来源。**旧实现每层有四个独立 `16×16×12×12×12×2` 实参数块：x/y分别保留 `0…11` 与 `−12…−1`，z保留 `0…11`。四层谱参数合计14,155,776个实数。[fno.py:56](../geobc/fno.py#L56)、[四象限切片:73](../geobc/fno.py#L73)。官方实现的12是每轴保留的总模式数，实空间数据把最后轴改为 `12//2+1=7`；每层只有一个 `16×16×12×12×7` complex dense tensor，x/y居中取 `−6…5`，z取 `0…6`，四层共1,032,192个复数条目。[模式转换:399](../third_party/neuraloperator/neuralop/layers/spectral_convolution.py#L399)、[权重形状:337](../third_party/neuraloperator/neuralop/layers/spectral_convolution.py#L337)、[频率切片:489](../third_party/neuraloperator/neuralop/layers/spectral_convolution.py#L489)。官方 dense 此处不是低秩压缩。两套成对FFT/iFFT的norm标签也不同，不能仅凭该标签把误差归因于归一化。

**计数须同口径。**完成摘要记录旧 FNO solver14,160,548 + PointNet16,736 = **14,177,284**；GINO1,416,541 + PointNet16,736 = **1,433,277**。[旧摘要](../runs/geobc_exploration/solver_screen_fno_480/summary.json#L5641)、[资源摘要:326](../runs/geobc_exploration/gino_native_resource_101_479/summary.json#L326)。两者都求 `sum(p.numel())`，但旧谱实部/虚部分开存储、每复数计2，官方 cfloat每复数计1。[旧计法:105](../geobc/solver_selection_models.py#L105)、[新计法:228](../tools/validate_gino_native_resource.py#L228)、[官方cfloat:353](../third_party/neuraloperator/neuralop/layers/spectral_convolution.py#L353)。按上述源码形状换算，GINO总计约 **2,465,469实标量自由度**；这是源码推导，非另一次运行测量。不可把14.18M对1.43M直接称十倍容量差，参数条目也不等同显存。

**其他同时改变的结构。**旧输入61 = occupancy1 + xyz3 + BC/material25 + global32，单层61→16 lifting，谱+pointwise支路，16→128→4 projection；前端是固定八点splat均值，输出八点trilinear查询。[选型封装:97](../geobc/solver_selection_models.py#L97)、[旧层:93](../geobc/fno.py#L93)、[splat:138](../geobc/solver_selection_data.py#L138)、[query:97](../geobc/solver_selection_data.py#L97)。GINO先由坐标嵌入/学习核对完整节点25作局部mean→grid25，再追加global32成为57，经57→32→16 lifting；默认块另有channel-MLP/skip，output GNO学习核与half_cos加权sum后16→64→4 projection。[适配器:171](../geobc/gino_solver.py#L171)、[官方lifting:296](../third_party/neuraloperator/neuralop/models/gino.py#L296)、[默认块:195](../third_party/neuraloperator/neuralop/models/gino.py#L195)、[projection:358](../third_party/neuraloperator/neuralop/models/gino.py#L358)。因此它不是只替换一个插值核；坐标进入学习GNO核，也未复制旧occupancy/xyz格点通道。

**screen报告规则：**同40/5 CAD、known3、TRAIN-only scaler、480案例更新/共同损失与顺序，报告全原节点指标、实际训练/编码/查询成本及上述实现/实复计数差异。结论比较两个完整候选，不能归因单核或称容量匹配。资源PASS仅覆盖fullN输入/512输出/一次无GT反向，不证明fullN训练、连续性或PDE准确；此时不增设官方FNO第三控制，只有GINO结果确需机制拆分时再另行预声明。
